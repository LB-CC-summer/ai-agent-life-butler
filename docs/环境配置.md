# 环境与密钥配置（成员 A 维护）

> 目标：让组里每个人**在 10 分钟内**从零把自己的电脑跑起来。
> 全程不需要把 Key 发给别人，也不需要 `.env` 进仓库。

---

## 一、准备两个 Key

### 1. 大模型 Key（三选一，都兼容 OpenAI 协议）

| 平台 | 注册地址 | 免费额度 | 建议模型 |
|---|---|---|---|
| DeepSeek（推荐） | <https://platform.deepseek.com/> | 新用户有赠送额度 | `deepseek-chat` |
| 阿里云百炼 / 通义千问 | <https://bailian.console.aliyun.com/> | 各模型有免费 Token | `qwen-plus` |
| 智谱 GLM | <https://open.bigmodel.cn/> | 有免费模型 | `glm-4-flash` |

操作：注册 → 实名认证 → 左侧「API Keys」→ 新建 → **复制一次，立刻存到本地记事本**（页面关掉就看不到了）。

### 2. 天气 API Key

推荐**高德开放平台**（免费、中文城市名直接查）：

1. 打开 <https://lbs.amap.com/> → 注册 → 实名认证（个人开发者即可）；
2. 控制台 → 应用管理 → 创建新应用（名称随便填，类型选"出行"）；
3. 为该应用**添加 Key** → 服务平台务必选 **「Web服务」**（选错成 JS API 会 401）；
4. 复制这串 Key。

> 备选：心知天气 <https://www.seniverse.com/>，和风天气 <https://dev.qweather.com/>。

## 二、本地配置（三步）

### 第 1 步：克隆仓库

```bash
git clone https://github.com/LB-CC-summer/ai-agent-life-butler.git
cd ai-agent-life-butler
```

### 第 2 步：安装依赖

```bash
pip install -r requirements.txt
```

> 建议先建虚拟环境，避免污染全局 Python：
> ```bash
> python -m venv .venv
> .venv\Scripts\activate      # Windows
> source .venv/bin/activate   # macOS / Linux
> ```

### 第 3 步：创建 `.env`

在**仓库根目录**（和 `requirements.txt` 同级）新建文件 `.env`，内容如下，把等号右边填成自己的值：

```ini
LLM_API_KEY=sk-你复制的大模型key
LLM_BASE_URL=https://api.deepseek.com
LLM_MODEL=deepseek-chat
WEATHER_API_KEY=你复制的天气key
WEATHER_API_HOST=https://restapi.amap.com
```

> 仓库里已经放好 `.env.example`，Windows 下可以直接复制粘贴再改名：
> `copy .env.example .env`（cmd）或 `Copy-Item .env.example .env`（PowerShell）。

```bash
streamlit run app_ui.py
```

> 上海今天天气怎么样

能返回带温度和天气现象的中文回答，说明两个 Key 都配好了。

## 四、常见问题

| 现象 | 原因 | 解决 |
|---|---|---|
| `KeyError: 'LLM_API_KEY'` 或回复里提示没 Key | `.env` 不在根目录 / 文件名写成了 `.env.txt` | 确认文件名为 `.env` 且与 `requirements.txt` 同级；Windows 要打开"显示文件扩展名"再改名 |
| `401 Unauthorized` | Key 复制不全 / 已过期 / 用错了平台 | 重新生成 Key |
| 天气返回 `INVALID_USER_KEY` | 高德 Key 类型选成了 JS API | 重新建一个「Web服务」类型的 Key |
| 天气返回 `INVALID_USER_SCODE` | 高德应用未完成实名认证 | 完成个人实名认证 |
| `ModuleNotFoundError: No module named 'streamlit'` | 依赖没装或装到了别的 Python | 确认 `pip -V` 与 `python -V` 指向同一环境，重装依赖 |
| `streamlit` 命令找不到 | 没进 PATH | 用 `python -m streamlit run app_ui.py` |
| 中文乱码 / `todo.txt` 打不开 | 编码问题 | 读写统一使用 `encoding="utf-8"` |

## 五、纪律（务必遵守）

1. **`.env` 永远不进仓库** —— `.gitignore` 已经排除，不要用 `git add -f` 强推；
2. **Key 不要发群里** —— 私聊或临时口令传递，作业提交前在平台上可以随时作废重建；
3. 提交前自查：`git status` 里不应出现 `.env`、`todo.txt`、`__pycache__/`；
4. 万一真的提交了 Key：立刻去平台**作废该 Key 并重新生成**，再清理 git 历史（`git filter-repo`），仅删除文件不够。
