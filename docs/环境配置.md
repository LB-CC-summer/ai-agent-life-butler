# 环境与密钥配置（成员 A 维护）

> 目标：让组里每个人**在 10 分钟内**从零把自己的电脑跑起来。
> 好消息：**只需要 1 个 Key**（大模型），天气接口免 Key。

---

## 一、准备 Key（只有一个）

### 大模型 Key

| 平台 | 注册地址 | 说明 |
|---|---|---|
| **DeepSeek（本项目使用）** | <https://platform.deepseek.com/> | 左侧「API Keys」→ 新建 → **只显示一次，立刻复制保存** |

> 代码里写死了 DeepSeek 的接口地址（`https://api.deepseek.com`），
> 想换通义千问 / 智谱也可以，在 `.env` 里改 `LLM_BASE_URL` 和 `LLM_MODEL` 即可（OpenAI 协议兼容）。

**不需要**申请天气 Key —— 天气数据来自 <https://wttr.in>，公开免费接口，一个 GET 就能查。

## 二、本地配置（三步）

### 第 1 步：克隆仓库

```bash
git clone https://github.com/LB-CC-summer/ai-agent-life-butler.git
cd ai-agent-life-butler
```

### 第 2 步：安装依赖

```bash
pip install -r requirements.txt
```

> 建议先建虚拟环境，避免污染全局 Python：
> ```bash
> python -m venv .venv
> .venv\Scripts\activate      # Windows
> source .venv/bin/activate   # macOS / Linux
> ```

### 第 3 步：创建 `.env`

在**仓库根目录**（和 `requirements.txt` 同级）新建文件 `.env`：

```ini
DEEPSEEK_API_KEY=sk-你复制的那串
```

可选覆盖项（不填就用默认值）：

```ini
LLM_MODEL=deepseek-flash
LLM_BASE_URL=https://api.deepseek.com
```

> 仓库里已放好 `.env.example`，直接复制改名再填值最快：
> `copy .env.example .env`（cmd）或 `Copy-Item .env.example .env`（PowerShell）。

## 三、验证

```bash
streamlit run app_ui.py
```

浏览器打开 `http://localhost:8501`，在输入框里问：

> 北京今天天气怎么样

再试一句「记一下明天买牙膏」，左侧待办面板应立刻出现一条带截止日期的待办，仓库根目录会生成 `todo.json`。

## 四、常见问题

| 现象 | 原因 | 解决 |
|---|---|---|
| 页面顶部黄条提示"还没有配置大模型 Key" | `.env` 不在根目录 / 文件名成了 `.env.txt` | 确认文件名就是 `.env`、与 `requirements.txt` 同级；Windows 打开"显示文件扩展名"再改名 |
| 回复"Key 没配对"或 401 | Key 复制不全 / 已过期 | 重新生成 Key 并更新 `.env`，然后刷新页面 |
| 回复"模型不存在"或 400 | 账号没有 `deepseek-flash` 模型权限 | 在 `.env` 里加 `LLM_MODEL=deepseek-chat` |
| `ModuleNotFoundError: streamlit / openai` | 依赖没装，或装到了别的 Python | 确认 `pip -V` 与 `python -V` 指向同一环境，重装依赖 |
| `streamlit` 命令找不到 | 没进 PATH | 用 `python -m streamlit run app_ui.py` |
| 界面报"核心模块加载失败" | 不在仓库根目录启动 | 一定要在 `app_ui.py` 同级目录运行命令 |
| 麦克风没反应 / 识别失败 | 未装 `SpeechRecognition`，或浏览器没授权麦克风 | `pip install SpeechRecognition`；浏览器地址栏点允许麦克风 |
| 语音识别报"服务连不上" | 识别走 Google 接口，网络受限 | 直接打字即可，其余功能不受影响 |
| 朗读没声音 | 浏览器禁用了语音合成 / 没装中文语音包 | 点一次「🔊 朗读上一条回复」手动触发；换 Edge 或 Chrome 试试 |
| 调用模型时报 `TypeError: process() takes no keyword arguments` | 本机 Brotli 版本过旧（1.0.9），新版 httpx 解压 br 压缩响应时传了关键字参数 | `pip install -U brotli`（升级到 1.1+ 即解决，实测 1.2.1 正常） |
| 页面一直转圈 / 请求超时 | 网络到 `api.deepseek.com` 不通 | 检查网络或代理；`curl https://api.deepseek.com` 应有响应 |

## 五、纪律（务必遵守）

1. **`.env` 永远不进仓库** —— `.gitignore` 已排除，不要用 `git add -f` 强推；
2. **Key 不要发群里** —— 私聊传递，作业提交前后都可随时作废重建；
3. `todo.json` 是运行产物，同样已被忽略，不要提交别人的待办数据；
4. 提交前自查：`git status` 里不应出现 `.env`、`todo.json`、`__pycache__/`；
5. 万一真提交了 Key：立刻去平台**作废并重新生成**，再清理 git 历史（`git filter-repo`），仅删文件不够。
