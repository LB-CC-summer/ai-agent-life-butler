## 一、`agent_brain.py` · 成员 B

```python
def get_agent_response(user_input: str, history: list = None) -> tuple[str, list]:
    """
    输入：
        user_input : 用户本轮输入的自然语言文本
        history    : 历史对话 [{"role": "user"|"assistant", "content": str}, ...]
                     可传 None，内部会新建空列表
    输出：
        (reply, history) —— 二元组！
            reply   : 给用户看的中文回复
            history : 更新后的历史（已追加本轮 user 与 assistant 两条）

    ⚠️ 两个必须注意的行为：
        1. 返回的是 tuple，不是 str。写成 `reply = get_agent_response(...)` 会拿到元组。
        2. 函数会**直接修改传入的 history 列表**（先 append user，最后 append assistant）。
           所以界面层应当传副本：get_agent_response(text, list(st.session_state.history))

    内部实现要点：
        - Function Calling 循环：模型可连续调多个工具（如先 search_task 再 done_task）
        - 只把纯文本对话写进 history，tool / tool_calls 消息一律不回填历史（防止下一轮 400）
        - 滑动窗口 MAX_HISTORY_MESSAGES = 20，超出从头裁剪
    """
```

### 2.2 待办（todo.json 持久化）

| 函数 | 签名 | 返回 |
|---|---|---|
| 新增 | `add_task(task_content: str, due_date: str = "") -> dict` | `{"success": True, "id": 1, "task": "...", "due_date": "..."}` |
| 列表 | `list_tasks(include_done: bool = False) -> dict` | `{"success": True, "tasks": [{id, task, due_date, done, status}]}`；无任务时附带 `message` |
| 搜索 | `search_task(keyword: str) -> dict` | `{"success": True, "tasks": [...]}` / 未命中 `{"success": False, "message": ...}` |
| 完成 | `done_task(task_id: int) -> dict` | `{"success": True, "message": "任务 [x] 已完成"}` |
| 修改 | `update_task(task_id, new_content="", new_due_date="") -> dict` | `{"success": True, "message": "任务修改成功", "task": {...}}` |
| 清理 | `clear_done_tasks() -> dict` | `{"success": True, "message": "已清理 N 条已完成任务。"}` |

补充说明：

- `status` 由 `list_tasks` 动态计算：`已逾期` / `今天截止` / `未到期`
- 存储文件：仓库根目录 `todo.json`（JSON 数组，已加入 `.gitignore`）
- 日期解析统一走内部 `_parse_date()`，把"周五""明天"转成 `YYYY-MM-DD`
